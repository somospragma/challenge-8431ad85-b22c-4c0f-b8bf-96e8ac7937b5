# Mejora la Experiencia de Usuario con Microinteracciones

Una aplicación web de finanzas personales busca mejorar la experiencia de usuario mediante la incorporación de microinteracciones en sus componentes clave. El objetivo es hacer que la interacción con la aplicación sea más intuitiva y agradable, reduciendo la fricción en tareas comunes como agregar una transacción, cambiar de vista o confirmar una acción.

### Fase 2: Diseñar la Microinteracción

**Objetivo:** Crear un diseño conceptual para una microinteracción en uno de los componentes seleccionados.

**Tiempo estimado:** 1 hora

**Instrucciones:**

**Entregable:** Un boceto o wireframe que muestre la microinteracción diseñada.

<details>
<summary>Pistas de conocimiento</summary>

**Entregable:** La microinteracción implementada y refinada en el componente de la aplicación.
